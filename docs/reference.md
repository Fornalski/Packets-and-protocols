# C syntax
## Library: <arpa/inet.h>

_htonl()_ - changes the order of bits from host to network order for 32-bit long unsigned intiger

_htons()_ - changes the order of bits from host to netwerk order for 16-bit long unsigned intiger

_ntohl()_ - changes the order of bit from network to host order for 32-bit long unsigned intiger

_ntohs()_ - changes the order of bit from network to host order for 16-bit long unsigned intiger
